# «Искатель» 2.5 — Десктопный поисковик с аккаунтами Google (Gmail), закладками и кастомизацией

«Искатель» — быстрое и легкое настольное приложение на Electron для приватного поиска в интернете без рекламы, слежки и трекеров. Приложение объединяет результаты нескольких независимых поисковых систем (DuckDuckGo и Bing), умеет показывать карточки Русской Википедии, мгновенные ответы и контекстные подсказки при наборе.

---

## 🚀 Что нового в версии 2.5

### 1. 👤 Система аккаунтов и вход через Google (Gmail)
- **Быстрый вход через Google:** кнопка «Продолжить с Google (Gmail)» позволяет в один клик привязать или создать аккаунт с вашей Gmail-почтой.
- **Регистрация и вход по Email/Паролю:** встроенная форма с валидацией почты и безопасным SHA-256 хешированием паролей на локальной стороне.
- **Интерактивное меню профиля в шапке:**
  - Отображение аватара пользователя с первой буквой имени.
  - Меню быстрого доступа: просмотр почты, переход к закладкам, открытие настроек и безопасный выход из аккаунта.

### 2. ⭐ Персональные закладки и история поиска
- В поисковой выдаче рядом с каждым результатом появилась звёздочка **☆ / ★**.
- Авторизованные пользователи могут сохранять важные сайты и статьи в персональные закладки.
- Модальное окно **«⭐ Мои закладки»** позволяет в любой момент просмотреть и открыть сохраненные ссылки или удалить ненужные.
- История поиска автоматически привязывается к активному профилю.

### 3. 🏷️ Индикатор версии в углу экрана
- Плавающий стеклянный бейдж **`v2.5`** с мягким свечением и пульсирующим зеленым индикатором статуса в правом нижнем углу.
- Нажатие на угловой бейдж открывает центр управления и окно настроек.

### 4. 🎨 Глубокая кастомизация интерфейса
- **7 акцентных дизайнерских палитр:** Индиго, Изумрудный, Киберпанк Циан, Закатный Оранжевый, Рубиновый, Золотой Янтарь и Монохром.
- Масштабирование шрифта (13px, 15px, 17px) и плотность списка результатов (просторная или компактная).
- Тумблеры фоновых сфер (Ambient Glow) и эффекта размытия матового стекла (Glassmorphism).

### 5. 🛠️ Безупречный интеллектуальный поиск
- Гарантированный многоуровневый переход на резервные движки (Bing, международные шлюзы) при задержках или коде HTTP 202 от DuckDuckGo.
- Никаких ложных сообщений «Ничего не найдено» при наличии карточек Википедии или быстрых ответов.

## 📦 Доступные установщики

Приложение автоматически компилируется под все популярные платформы:

| Операционная система | Архитектура | Имя файла в GitHub Release |
|---|---|---|
| **Windows 10 / 11** | 64-bit (x64) | `iskatel-win64-setup.exe` |
| **macOS (M1 / M2 / M3 / M4)** | Apple Silicon (arm64) | `iskatel-mac-arm64.dmg` |
| **macOS (Intel Mac)** | Intel (x64) | `iskatel-mac-intel.dmg` |
| **Linux (Ubuntu / Debian / Mint)** | 64-bit (amd64) | `iskatel-linux-amd64.deb` |

---

## 🍏 Инструкция по запуску на macOS

1. Скачайте `.dmg` файл под вашу архитектуру (Apple Silicon для M1/M2/M3/M4 или Intel).
2. Перетащите «Искатель» в системную папку **«Программы»** (Applications).
3. При первом открытии: клик правой кнопкой мыши → **«Открыть»** → подтвердить.
4. *(Если Gatekeeper блокирует запуск без подписи Apple)* выполните в Терминале:
   ```bash
   xattr -cr "/Applications/Искатель.app"
   ```

## 💻 Локальный запуск и сборка

```bash
git clone https://github.com/UsmanMusav/Iskatel.git
cd Iskatel
npm install
npm start
```

Сборка установщиков:
- `npm run dist:win` — Windows NSIS 64-bit установщик
- `npm run dist:linux` — пакет Debian/Ubuntu (.deb)
- `npm run dist:mac` — образы macOS (.dmg)
