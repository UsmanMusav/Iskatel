# Proton 2.7.1 — Черно-белый браузер с вкладками в стиле Chrome

**Proton** (ранее «Искатель») — быстрый, лаконичный десктопный браузер на Electron для приватного поиска и комфортного серфинга в интернете без рекламы, слежки и трекеров. Приложение объединяет результаты нескольких независимых поисковых систем (DuckDuckGo и Bing), отображает карточки Русской Википедии и мгновенные ответы, поддерживает авторизацию через Google (Gmail), персональные закладки, изолированную систему вкладок в стиле Google Chrome и коллекцию стилей оформления с комфортным черно-белым дизайном по умолчанию.

---

## 🚀 Что нового в версии 2.7.1

### 1. 🖤 Черно-белый монохромный дизайн по умолчанию
- Базовая цветовая палитра переведена на строгий, контрастный и стильный черно-белый дизайн (Monochrome Dark).
- Высококонтрастные элементы управления: белоснежные кнопки поиска и переходов с контрастными черными стрелками `→`.

### 2. 🪨 Комфортный мягкий темный фон
- Отказ от резкого слепящего смоляного черного (`#000000`) в пользу мягкого, приятного для глаз темного графита (`#16171d` / `#1c1d25`).
- Оптимальный контраст для длительной работы как днём, так и ночью без усталости глаз.

### 3. 🌐 Вкладки и навигация в точности как в Google Chrome
- **Chrome Tab Strip:** полоса вкладок на самом верху окна. Вкладки имеют скругленную геометрию Chrome (`9px 9px 0 0`) и бесшовно перетекают в навигационную панель снизу.
- **Интегрированная кнопка `+`:** создание новой вкладки прямо рядом с текущими вкладками.
- **Chrome Navigation Toolbar:** под полосой вкладок расположена полноценная панель управления:
  * `[ ‹ ]` — Назад по истории текущей вкладки (`Alt+Left`)
  * `[ › ]` — Вперёд по истории текущей вкладки (`Alt+Right`)
  * `[ ↻ ]` — Перезагрузка вкладки со стильной плавной анимацией вращения (`Ctrl+R` / `F5`)
  * `[ Omnibox ]` — Универсальная адресная и поисковая строка со встроенной кнопкой перехода `→` и очисткой `✕`
  * `[ Профиль / Вход ]` — Быстрый доступ к аккаунту Google и закладкам
  * `[ ⚙ ]` — Настройки браузера
- **Полная изоляция сессий:** переключение между вкладками происходит мгновенно с сохранением точного состояния DOM, текста запросов, результатов поиска и позиции прокрутки.
- **Управление вкладками:**
  * Закрытие по крестику `✕` или клику средней кнопкой мыши (колесиком).
  * Двойной клик по свободной области полосы вкладок создает новую вкладку.
  * Контекстное меню по правому клику: Перезагрузить, Дублировать, Новая вкладка, Закрыть, Закрыть другие.
  * Горячие клавиши: `Ctrl+T` (новая), `Ctrl+W` (закрыть), `Ctrl+R` (обновить), `Ctrl+Tab` (следующая).

### 4. ✨ Стильное футуристическое оформление главной страницы
- Заголовок **Proton** выполнен в премиальной металлизированной типографике с многослойным градиентом и мягким свечением.
- Футуристический бейдж `PROTON BROWSER v2.7.1` с пульсирующим неоновым индикатором.
- Квантовый логотип с вращающимися орбитальными кольцами электронов при наведении.
- Лаконичный слоган: *«Быстрый · Приватный · Минималистичный»*.

### 5. 🎬 Больше плавных микро-анимаций
- Плавные переходы и эффекты скругления при переключении вкладок.
- Анимация кругового вращения кнопки перезагрузки (`spinReload`).
- Плавное раскрытие карточек поисковой выдачи каскадным эффектом (`cardReveal`).
- Интерактивное увеличение и подсветка Omnibox при фокусе.
- Мягкое появление модальных окон и выпадающего меню профиля.

### 6. 🎨 100% надежная система стилей оформления
Устранены конфликты в переключении тем оформления. В разделе **«Настройки» → «Оформление»** доступны 7 стилей:
1. 🖤 **Monochrome Dark (По умолчанию)** — стильный мягкий черно-белый графит.
2. ⚪ **Классический Искатель (Старый стиль)** — оригинальная светлая тема, доступная в один клик.
3. 🌌 **Midnight Blue** — глубокие полуночно-синие оттенки.
4. ⚡ **Cyberpunk Neon** — тёмный неоновый киберпанк с циан-подсветкой.
5. 🪨 **Carbon Graphite** — нейтральный матовый графит.
6. 🌲 **Emerald Night** — хвойно-зелёный глубокий ночной стиль.
7. ❄️ **Nordic Frost** — чистый скандинавский светлый минимализм.

## 🛠️ Сборка из исходников

```bash
# Клонирование репозитория
git clone https://github.com/UsmanMusav/Iskatel.git
cd Iskatel

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка пакетов для текущей ОС
npm run dist
```
