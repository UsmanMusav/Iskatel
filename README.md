# «Искатель» 2.0 — Быстрый и настраиваемый десктопный поисковик

«Искатель» — быстрое и легкое настольное приложение на Electron для приватного поиска в интернете без назойливой рекламы, слежки и трекеров. Приложение объединяет результаты нескольких независимых поисковых систем (DuckDuckGo и Bing), умеет показывать карточки Русской Википедии, мгновенные ответы и контекстные подсказки при наборе.

---

## 🚀 Что нового в версии 2.0

### 1. 🏷️ Индикатор версии в углу экрана
- В нижнем правом углу рабочего пространства появился элегантный плавающий бейдж версии `v2.0` с эффектом матового стекла и пульсирующим статусным индикатором.
- Нажатие на угловой бейдж открывает центр управления: информацию о сборке, статус актуальности и быстрый доступ к проверке обновлений.

### 2. 🎨 Глубокая кастомизация интерфейса
- **7 дизайнерских акцентных палитр:**
  - 🟣 *Индиго* (фирменный неоновый акцент)
  - 🟢 *Изумруд* (свежий природный зеленый)
  - 🔵 *Киберпанк* (электрический циан)
  - 🟠 *Закатный Оранжевый* (теплый энергичный)
  - 🔴 *Рубин* (глубокий контрастный)
  - 🟡 *Золотой Янтарь* (мягкий солнечный)
  - 🖤 *Монохром* (строгий сдержанный минимализм)
- **Гибкие режимы отображения:**
  - Светлая, тёмная или автоматическая адаптация под тему операционной системы.
  - Масштабирование шрифтов: компактный (13px), стандартный (15px), крупный (17px).
  - Плотность выдачи: просторная (для комфортного чтения) или компактная (для максимального объема информации на экране без лишнего скролла).
  - Настройка фоновых эффектов: включение/выключение динамических световых сфер (Ambient Glow) и эффекта размытия матового стекла (Glassmorphism).

### 3. 🛠️ Исправление бага «Ничего не найдено»
- **Устранён сбой ложного пустого результата:** ранее при временной блокировке или ответе HTTP 202 от одного из поисковых движков приложение могло ошибочно сообщать, что «Ничего не найдено», даже если по запросу существовали сотни страниц.
- **Интеллектуальный многоуровневый фолбэк:** если основной движок возвращает 0 результатов или задерживает ответ, «Искатель» мгновенно обращается к резервным источникам (Bing, международные шлюзы) и гарантирует качественную выдачу.
- **Корректный учёт мгновенных ответов:** если по запросу найдена статья Википедии или блок быстрых ответов (калькулятор, факты), приложение больше никогда не выводит ложную плашку «Ничего не найдено».

### 4. 🔄 Автообновление и совместимость
- Клиенты версии `1.1.0` обнаружат релиз `v2.0.0` через GitHub Releases API и предложат обновиться в 1 клик.
- Версия `2.0.0` включает встроенный модуль проверки и скачивания установщиков под все платформы.

## 📦 Точные имена файлов в GitHub Releases

Клиент «Искателя» ищет установщики строго под следующими именами:

| Платформа | Архитектура | Имя файла в релизе |
|---|---|---|
| **Windows 10 / 11** | 64-bit (x64) | `iskatel-win64-setup.exe` |
| **macOS** | Apple Silicon (M1 / M2 / M3 / M4) | `iskatel-mac-arm64.dmg` |
| **macOS** | Intel (x64) | `iskatel-mac-intel.dmg` |
| **Linux (Ubuntu / Debian / Mint)** | 64-bit (amd64) | `iskatel-linux-amd64.deb` |

## 🛠 Автоматическая сборка всех платформ (CI/CD)

В репозитории настроен GitHub Actions workflow (`.github/workflows/release.yml`):
- При пуше тега `v2.0.0` GitHub Actions автоматически собирает установщики на раннерах Windows, macOS и Ubuntu и прикрепляет их к релизу с точными именами файлов.

## 💻 Локальный запуск и разработка

```bash
git clone https://github.com/UsmanMusav/Iskatel.git
cd Iskatel
npm install
npm start
```

Сборка установщиков:
- `npm run dist:win` — установщик для Windows (NSIS 64-bit)
- `npm run dist:linux` — пакет Debian/Ubuntu (.deb)
- `npm run dist:mac` — образ диска macOS (.dmg)
