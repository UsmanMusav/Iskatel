# Proton 2.8.2 — Стабильный релиз: полное исправление кликабельности, поиска и автообновления

Proton (ранее «Искатель») — быстрый, лаконичный десктопный браузер на Electron для приватного поиска и комфортного серфинга в интернете без рекламы, слежки и трекеров. Приложение объединяет результаты нескольких независимых поисковых систем (DuckDuckGo и Bing), отображает карточки Русской Википедии и мгновенные ответы, поддерживает авторизацию через Google (Gmail), персональные закладки, изолированную систему вкладок в стиле Google Chrome, установку собственных фото-обоев на фон, голосовой ввод и встроенное автообновление в один клик.

## Что нового в версии 2.8.2

### 1. Полное устранение блокировки нажатий и кнопок (Критический фикс)
- **Причина проблемы в предыдущей сборке:** Окна настроек, авторизации и закладок использовали свойство `backdrop-filter: blur(8px)` на полноэкранных оверлеях (`inset: 0`) с `display: grid`. В движке Chromium (Blink) такой оверлей создавал прозрачный композитный слой аппаратного ускорения, который перехватывал события мыши (hit-testing) даже при установленном `pointer-events: none`. В результате интерфейс переставал реагировать на клики.
- **Исправление:** Все закрытые модальные окна теперь строго скрыты через `display: none !important`. Композитные слои полностью удалены из дерева отрисовки, что гарантирует 100% отзывчивость всех кнопок, вкладок, полей ввода и иконок на всех платформах.

### 2. Гарантированный запуск инициализации интерфейса
- **Причина проблемы:** Ранее регистрация обработчиков опиралась исключительно на событие `DOMContentLoaded`. При быстром локальном открытии страницы в Electron событие могло сработать до завершения выполнения скрипта, из-за чего обработчики поиска и кнопок не подключались.
- **Исправление:** Добавлена строгая проверка `document.readyState`: если документ уже находится в состоянии `interactive` или `complete`, функция `init()` запускается мгновенно.
- Все модули инициализации обёрнуты в независимые блоки `try...catch`, а поисковые формы снабжены атрибутами `action="javascript:void(0);"` и защитой от случайной перезагрузки окна.

### 3. Безотказный поиск и защита от зависаний сети
- Во все сетевые запросы (`fetch`) в главном процессе Electron добавлены строгие таймауты `AbortSignal.timeout(...)`. Поисковый запрос больше никогда не может «зависнуть» на бесконечно пульсирующих скелетонах.
- Реализован автоматический переход на прямой веб-навигатор (Яндекс, Google, Википедия, YouTube), если внешние движки временно недоступны или заблокированы провайдером.

### 4. Голосовой поиск (Voice Search) и надежный In-App Updater
- Сохранён и отлажен голосовой поиск с пульсирующей анимацией и автоматической отправкой запроса.
- В главном процессе настроены обработчики разрешений микрофона `session.defaultSession.setPermissionRequestHandler`.
- Работает удобное скачивание установщиков с показом прогресса (МБ и проценты) и автоперезапуск приложения.

## Установка и запуск из исходного кода

```bash
git clone https://github.com/UsmanMusav/Iskatel.git
cd Iskatel
npm install
npm start
```

### Сборка установщиков
- Для Windows: `npm run dist:win`
- Для Linux: `npm run dist:linux`
- Для macOS: `npm run dist:mac`
