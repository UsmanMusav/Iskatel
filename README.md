# Proton 2.8.1 — Браузер с голосовым поиском, автообновлением и вкладками

Proton (ранее «Искатель») — быстрый, лаконичный десктопный браузер на Electron для приватного поиска и комфортного серфинга в интернете без рекламы, слежки и трекеров. Приложение объединяет результаты нескольких независимых поисковых систем (DuckDuckGo и Bing), отображает карточки Русской Википедии и мгновенные ответы, поддерживает авторизацию через Google (Gmail), персональные закладки, изолированную систему вкладок в стиле Google Chrome, установку собственных фото-обоев на фон, голосовой ввод и встроенное автообновление в один клик.

## Что нового в версии 2.8.1

### 1. Исправлено и доработано обновление через приложение (In-App Updater)
В версиях 2.7 и 2.8 кнопка обновления лишь уведомляла о новой версии или требовала перехода на сайт. В Proton 2.8.1 механизм обновлений полностью переработан и доведён до идеала:
- **Проверка в один клик:** В окне «Настройки» → вкладка «Обновления» приложение мгновенно запрашивает последний релиз на GitHub.
- **Встроенная загрузка с прогресс-баром:** При наличии обновления отображается карточка с номером версии, размером файла и списком изменений. Нажатие кнопки «Скачать и установить обновление» запускает скачивание файла прямо внутри Proton с отображением процентов и количества загруженных мегабайт в реальном времени.
- **Корректный запуск и перезапуск:** Исправлена проблема блокировки файлов в Windows — Proton запускает скачанный установщик (`iskatel-win64-setup.exe`) и корректно завершает свою работу, позволяя установщику беспрепятственно обновить файлы приложения.
- **Умное перенаправление HTTP:** Загрузчик в `main.js` теперь устойчиво обрабатывает многократные редиректы CDN GitHub (`objects.githubusercontent.com`) и очищает временные файлы при сбоях.

### 2. Голосовой ввод и голосовой поиск (Voice Search)
В интерфейс добавлен полноценный голосовой ввод без использования эмодзи:
- **Кнопка микрофона:** Изящная векторная SVG-иконка микрофона размещена как в большой строке поиска на главной странице, так и в компактном Omnibox панели навигации.
- **Пульсирующая индикация записи:** При нажатии микрофон переходит в активный режим с мягкой красной пульсирующей анимацией (`pulseVoice`), а в поле ввода появляется подсказка «Слушаю вас… говорите».
- **Автоматический поиск:** Распознанный текст на лету отображается в строке ввода, а по завершении фразы поиск запускается автоматически.
- **Поддержка разрешений в Electron:** В главном процессе настроен обработчик прав доступа к медиаустройствам (`session.defaultSession.setPermissionRequestHandler`), благодаря чему голосовой ввод работает стабильно и без системных блокировок.

### 3. Полный отказ от эмодзи
- Строгий, профессиональный минималистичный стиль с SVG-иконками во всех диалогах, кнопках и карточках.

### 4. Своя фотография на задний фон поисковика (Обои)
- В разделе **«Настройки» → «Оформление и фон»**:
  * Загрузка изображения с компьютера или по прямой веб-ссылке.
  * Режимы масштабирования: Заполнение экрана (Cover), Вписать целиком (Contain), Растянуть (Stretch), Оригинал (Auto).
  * Позиционирование (центр, верх, низ, слева, справа).
  * Плавное затемнение (0–90%) и размытие (0–25px).
  * 100% четкий заголовок Proton с защитой от сливания.

### 5. Вкладки и навигация в стиле Chrome
- Горячие клавиши: `Ctrl+T` (новая вкладка), `Ctrl+W` (закрыть вкладку), `Ctrl+R` / `F5` (перезагрузить), `Ctrl+Tab` / `Ctrl+Shift+Tab` (переключение).
- Навигация вперед/назад (`Alt+Left`, `Alt+Right`).
- Независимое сохранение запросов, результатов и скролла для каждой вкладки.

## Установка и запуск из исходного кода

### Требования
- **Node.js** версии 18 или новее
- Менеджер пакетов **npm**

### Клонирование и установка зависимостей
```bash
git clone https://github.com/UsmanMusav/Iskatel.git
cd Iskatel
npm install
```

### Запуск в режиме разработки
```bash
npm start
```

### Сборка установщиков для вашей ОС
- Для текущей платформы: `npm run dist`
- Для Windows (Setup + Portable): `npm run dist:win`
- Для Linux (.deb): `npm run dist:linux`
- Для macOS (.dmg): `npm run dist:mac`
