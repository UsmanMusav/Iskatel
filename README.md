# Proton 2.9.0 — Умный ИИ-помощник в стиле Google Assistant, голосовая озвучка и структурированные выжимки

Proton (ранее «Искатель») — быстрый, лаконичный десктопный браузер на Electron для приватного поиска и комфортного серфинга в интернете без рекламы, слежки и трекеров. Приложение объединяет результаты нескольких независимых поисковых систем (DuckDuckGo и Bing), отображает встроенный умный ИИ-обзор (AI Overview) с голосовой озвучкой в стиле Google Assistant, карточки Русской Википедии и мгновенные ответы, поддерживает авторизацию через Google (Gmail), персональные закладки, изолированную систему вкладок в стиле Google Chrome, установку собственных фото-обоев на фон, голосовой ввод и встроенное автообновление в один клик.

## Что нового в версии 2.9.0

### 1. Интегрированный ИИ-помощник (Google Assistant / AI Overview)
- **Мгновенный структурированный ответ:** При поиске над списком найденных сайтов формируется аккуратная карточка с краткой фактологической выжимкой (2–3 предложения), ключевыми тезисами и списком проверенных первоисточников.
- **Встроенный нейросинтез (0 ключей, бесплатно):** Работает «из коробки» без необходимости регистрироваться, вводить API-ключи или настраивать сервера. Анализирует энциклопедические выжимки Википедии, мгновенные факты и сниппеты поисковой выдачи.
- **Поддержка внешних LLM:** В настройках доступен выбор популярных провайдеров искусственного интеллекта:
  - **Groq Cloud:** сверхбыстрые модели Llama 3.3 70B Versatile;
  - **OpenAI:** модели GPT-4o-mini и GPT-4o;
  - **DeepSeek:** передовые модели DeepSeek V3 и DeepSeek R1;
  - **Ollama:** локальные модели (Llama 3.2, Qwen и др.) прямо на вашем компьютере без отправки данных в сеть;
  - **Пользовательский API:** любой OpenAI-совместимый сервер.
- **Безотказный авторезерв:** Если внешняя нейросеть временно недоступна, превысила лимит или произошел таймаут, приложение автоматически переключается на встроенный синтез.

### 2. Голосовая озвучка ответа (Text-to-Speech)
- **Кнопка «Озвучить»:** В заголовке карточки ИИ-помощника добавлена кнопка голосового воспроизведения с живой анимацией эквалайзера.
- **Синтез речи в стиле Google Assistant:** Автоматически подбираются лучшие доступные русскоязычные голоса операционной системы и браузера.
- **Автоматическое озвучивание:** В настройках можно включить опцию автоматического зачитывания ответа сразу после завершения поиска.
- **Регулировка темпа речи и выбор голоса:** Ползунок скорости речи от 0.8x до 1.4x и выпадающий список системных голосов с возможностью прослушивания образца в настройках.

### 3. Расширенная вкладка «ИИ-помощник» в настройках
- Новая отдельная вкладка **«ИИ-помощник»** в окне настроек Proton:
  - Включение / выключение ИИ-обзора;
  - Переключатель автоматической озвучки;
  - Выбор модели и движка;
  - Ввод API-ключа, выбор названия модели и адреса эндпоинта;
  - Кнопка «Проверить подключение» с мгновенной валидацией связи с выбранной моделью;
  - Выбор голоса озвучивания и скорости речи.

### 4. Полная интеграция с вкладками и сессиями
- Состояние сгенерированного ИИ-ответа (текст, ключевые пункты, источники, кнопки управления) сохраняется индивидуально для каждой открытой вкладки. При переключении между вкладками ничего не сбрасывается.
- При переходе на другую вкладку или запуске нового поиска воспроизведение речи автоматически останавливается.

## Установка и запуск из исходного кода

```bash
git clone https://github.com/UsmanMusav/Iskatel.git
cd Iskatel
npm install
npm start
```

### Сборка установщиков
- Для Windows: `npm run dist:win`
- Для Linux: `npm run dist:linux`
- Для macOS: `npm run dist:mac`
