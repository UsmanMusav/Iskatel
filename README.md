# Proton 2.11.0 — Полная автономность: встроенный просмотр веб-сайтов во вкладках без Google Chrome

Proton (ранее «Искатель») — быстрый, лаконичный десктопный браузер на Electron для приватного поиска и комфортного серфинга в интернете без рекламы, слежки и трекеров. Proton работает полностью автономно и не требует наличия или запуска Google Chrome: сайты открываются прямо внутри вкладок приложения. Браузер объединяет результаты нескольких независимых поисковых систем (DuckDuckGo и Bing), отображает встроенный умный ИИ-обзор (AI Overview) с голосовой озвучкой в стиле Google Assistant, боковую панель интерактивного ИИ-Копилота (Proton Copilot), карточки Русской Википедии и мгновенные ответы, поддерживает авторизацию через Google (Gmail), персональные закладки, изолированную систему вкладок в стиле Google Chrome, установку собственных фото-обоев на фон, голосовой ввод и встроенное автообновление в один клик.

## Что нового в версии 2.11.0

### 1. Полная автономность от Google Chrome (In-App Tab Web Browser)
- **Встроенный просмотр веб-страниц:** Все ссылки из поисковой выдачи, карточек Википедии, мгновенных ответов, источников ИИ-обзора и закладок открываются непосредственно внутри Proton во вкладках через изолированный `<webview>`.
- **Никаких сторонних окон:** Браузер больше не передаёт URL во внешние браузеры (Google Chrome, Edge или Safari) — полный цикл веб-серфинга происходит внутри единого окна Proton.
- **Прямой ввод веб-адресов в Омнибокс:** Ввод любого домена или ссылки (например, `github.com`, `wikipedia.org`, `localhost:3000`, `https://...`) мгновенно открывает сайт в активной вкладке.
- **Поддержка открытия в новых вкладках:** Клик с зажатой клавишей `Ctrl` (или `Cmd` на macOS) либо клик колёсиком мыши (средней кнопкой) открывает ссылку в новой вкладке Proton.

### 2. Продвинутая навигация и статус страниц
- **Кнопки навигации:** Полнофункциональные кнопки «Назад» (Alt+Left), «Вперёд» (Alt+Right), «Перезагрузить» (Ctrl+R / F5) и новая кнопка «Главная» в навигационной панели.
- **Индикаторы и Favicon:** На вкладках отображаются анимированный индикатор загрузки, иконки веб-сайтов (favicon) и динамические заголовки открытых страниц.
- **Полоса загрузки (Web Load Bar):** Тонкий градиентный прогресс-бар в верхней части веб-страницы информирует о ходе загрузки.
- **Экран восстановления при сбоях сети:** В случае ошибки сети или неверного адреса отображается карточка с кодом ошибки и кнопками «Повторить попытку» и «Вернуться к поиску».

## Что появилось в версии 2.10.0

### 1. Выдвижная боковая панель ИИ-Копилота (Proton Copilot)
- **Горячая клавиша `Ctrl+J` (или кнопка в шапке):** Мгновенно открывает и закрывает боковую панель ИИ-помощника справа, не перекрывая контент страницы.
- **Интерактивные быстрые действия (Quick Actions):**
  - **«Краткая суть»:** Мгновенно формирует лаконичное резюме темы или страницы;
  - **«Главные факты»:** Выделяет ключевые числовые показатели, даты и тезисы;
  - **«Объясни просто»:** Пересказывает сложную терминологию простым языком для новичков;
  - **«Сравнение»:** Анализирует особенности, плюсы и минусы;
  - **«Перевод»:** Переводит и структурирует международные термины.
- **Полноценный многошаговый диалог:** Возможность вести непрерывную беседу с ассистентом, задавать уточняющие вопросы и получать развернутые ответы.
- **Голосовой ввод вопроса прямо в Copilot:** Иконка микрофона позволяет надиктовать вопрос голосом, после чего он автоматически отправляется ассистенту.
- **Озвучка ответов Копилота (Text-to-Speech):** У каждого ответа ассистента в чате есть кнопка «Озвучить» для голосового прослушивания.

### 2. Контекстная осведомленность и поддержка внешних LLM
- Копилот видит текущую активную поисковую тему вкладки, сниппеты и энциклопедические данные Википедии.
- Поддерживает как **встроенный автономный синтез без API-ключей**, так и подключенные модели из настроек:
  - Groq Cloud (Llama 3.3 70B);
  - OpenAI (GPT-4o / GPT-4o-mini);
  - DeepSeek (V3 / R1);
  - Ollama (локальные модели);
  - Любой пользовательский OpenAI-совместимый сервер.

## Установка и запуск из исходного кода

```bash
git clone https://github.com/UsmanMusav/Iskatel.git
cd Iskatel
npm install
npm start
```

### Сборка установщиков
- Для Windows: `npm run dist:win`
- Для Linux: `npm run dist:linux`
- Для macOS: `npm run dist:mac`
