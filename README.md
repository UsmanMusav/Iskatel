# Proton 2.10.0 — Интерактивный ИИ-Копилот (Copilot Side-Panel), многошаговый диалог и голосовое взаимодействие

Proton (ранее «Искатель») — быстрый, лаконичный десктопный браузер на Electron для приватного поиска и комфортного серфинга в интернете без рекламы, слежки и трекеров. Приложение объединяет результаты нескольких независимых поисковых систем (DuckDuckGo и Bing), отображает встроенный умный ИИ-обзор (AI Overview) с голосовой озвучкой в стиле Google Assistant, боковую панель интерактивного ИИ-Копилота (Proton Copilot), карточки Русской Википедии и мгновенные ответы, поддерживает авторизацию через Google (Gmail), персональные закладки, изолированную систему вкладок в стиле Google Chrome, установку собственных фото-обоев на фон, голосовой ввод и встроенное автообновление в один клик.

## Что нового в версии 2.10.0

### 1. Выдвижная боковая панель ИИ-Копилота (Proton Copilot)
- **Горячая клавиша `Ctrl+J` (или кнопка в шапке):** Мгновенно открывает и закрывает боковую панель ИИ-помощника справа, не перекрывая контент страницы.
- **Интерактивные быстрые действия (Quick Actions):**
  - **«Краткая суть»:** Мгновенно формирует лаконичное резюме темы или страницы;
  - **«Главные факты»:** Выделяет ключевые числовые показатели, даты и тезисы;
  - **«Объясни просто»:** Пересказывает сложную терминологию простым языком для новичков;
  - **«Сравнение»:** Анализирует особенности, плюсы и минусы;
  - **«Перевод»:** Переводит и структурирует международные термины.
- **Полноценный многошаговый диалог:** Возможность вести непрерывную беседу с ассистентом, задавать уточняющие вопросы и получать развернутые ответы.
- **Голосовой ввод вопроса прямо в Copilot:** Иконка микрофона позволяет надиктовать вопрос голосом, после чего он автоматически отправляется ассистенту.
- **Озвучка ответов Копилота (Text-to-Speech):** У каждого ответа ассистента в чате есть кнопка «Озвучить» для голосового прослушивания.

### 2. Контекстная осведомленность и поддержка внешних LLM
- Копилот видит текущую активную поисковую тему вкладки, сниппеты и энциклопедические данные Википедии.
- Поддерживает как **встроенный автономный синтез без API-ключей**, так и подключенные модели из настроек:
  - Groq Cloud (Llama 3.3 70B);
  - OpenAI (GPT-4o / GPT-4o-mini);
  - DeepSeek (V3 / R1);
  - Ollama (локальные модели);
  - Любой пользовательский OpenAI-совместимый сервер.

## Установка и запуск из исходного кода

```bash
git clone https://github.com/UsmanMusav/Iskatel.git
cd Iskatel
npm install
npm start
```

### Сборка установщиков
- Для Windows: `npm run dist:win`
- Для Linux: `npm run dist:linux`
- Для macOS: `npm run dist:mac`
