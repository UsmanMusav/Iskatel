# «Искатель» — быстрый десктопный поисковик

«Искатель» — быстрое и легкое настольное приложение на Electron для поиска в интернете без назойливой рекламы, слежки и трекеров. Приложение объединяет результаты DuckDuckGo и Bing, умеет показывать карточки Википедии, мгновенные ответы и контекстные подсказки при наборе.

---

## 🚀 Возможности версии 1.1.0

- 🔍 **Умный гибридный поиск:** основной поиск через DuckDuckGo с автоматическим резервным переключением на Bing при сбоях сети или ограничениях.
- 📖 **Мгновенные справки и факты:** прямая интеграция со статьями Русской Википедии и блоками Instant Answers.
- ⚙️ **Окно настроек:**
  - Выбор основного поискового движка (Авто / DuckDuckGo / Bing).
  - Настройка региона и языка выдачи (`ru-ru`, `wt-wt`, `us-en`, `de-de`).
  - Переключение светлой, тёмной или системной цветовой темы.
- 🔄 **Встроенный механизм проверки и установки обновлений:**
  - Клиент проверяет актуальный релиз через [GitHub Releases API](https://api.github.com/repos/UsmanMusav/Iskatel/releases/latest).
  - Текущая версия `1.1.0` является **базовой**: она содержит апдейтер и не будет предлагать обновление сама себе.
  - При появлении новой версии (например, `1.1.1`) приложение уведомит пользователя, отобразит описание изменений, скачает системный установщик с индикатором прогресса и запустит установку.

> **Важно для пользователей версии 1.0.0:** старые сборки 1.0.0 не содержат модуля автообновления. Для перехода на систему обновлений их необходимо обновить до версии **1.1.0 вручную**, скачав установщик из репозитория. Все последующие версии будут обновляться автоматически через интерфейс приложения.

Клиент «Искателя» ищет установщики строго под следующими именами:

| Платформа | Архитектура | Имя файла в релизе |
|---|---|---|
| **Windows 10 / 11** | 64-bit (x64) | `iskatel-win64-setup.exe` |
| **macOS** | Apple Silicon (M1 / M2 / M3 / M4) | `iskatel-mac-arm64.dmg` |
| **macOS** | Intel (x64) | `iskatel-mac-intel.dmg` |
| **Linux (Ubuntu / Debian / Mint)** | 64-bit (amd64) | `iskatel-linux-amd64.deb` |

## 🛠 Автоматическая сборка всех платформ (CI/CD)

В репозитории настроен GitHub Actions workflow (`.github/workflows/release.yml`), который полностью автоматизирует процесс:

1. Вы создаете новый тег версии:
   ```bash
   git tag v1.1.1
   git push origin v1.1.1
   ```
2. GitHub Actions параллельно запускает сборку на раннерах Windows, macOS и Ubuntu.
3. Готовые файлы компилируются и загружаются в GitHub Release с точными ожидаемыми именами.

Также workflow можно запустить вручную во вкладке **Actions → Build & Release Desktop Installers → Run workflow**.

## 💻 Локальная разработка и сборка

### Требования
- Node.js 18+ (рекомендуется 20 LTS)
- npm 9+

### Запуск в режиме разработки
```bash
git clone https://github.com/UsmanMusav/Iskatel.git
cd Iskatel
npm install
npm start
```

### Сборка установщиков вручную
- Для Windows:
  ```bash
  npm run dist:win
  ```
- Для Linux (.deb):
  ```bash
  npm run dist:linux
  ```
- Для macOS (.dmg):
  ```bash
  npm run dist:mac
  ```
