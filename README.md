# Proton 2.7 — Ультра-минималистичный черный браузер с вкладками

**Proton** (ранее «Искатель») — быстрое, лаконичное и ультра-минималистичное десктопное приложение на Electron для приватного поиска и серфинга в интернете без рекламы, слежки и трекеров. Приложение объединяет результаты нескольких независимых поисковых систем (DuckDuckGo и Bing), умеет показывать карточки Русской Википедии, мгновенные ответы, поддерживает авторизацию через Google (Gmail), персональные закладки, систему независимых вкладок и переключаемые стили оформления с глубоким черным OLED-режимом по умолчанию.

## 🚀 Что нового в версии 2.7: Вкладки, черный стиль и Proton

### 1. ⚛️ Ребрендинг: «Искатель» теперь Proton
- Новое технологичное имя **Proton** и обновленный современный квантовый логотип.
- Фокус на скорости, приватности и лаконичном дизайне без визуального шума.

### 2. 📑 Полноценная система вкладок (Tabs System)
- **Создание вкладок:** кнопка `+` на панели вкладок или горячая клавиша `Ctrl+T` (на macOS: `Cmd+T`), а также двойной клик по свободной области полосы вкладок.
- **Независимые сессии:** каждая вкладка сохраняет собственный поисковый запрос, результаты выдачи, позицию прокрутки и домашнее состояние без повторных запросов к сети.
- **Закрытие вкладок:** кнопка `×`, средняя кнопка мыши (колесико) или комбинация `Ctrl+W` (`Cmd+W`).
- **Перезагрузка вкладок:** специальная кнопка `↻` на панели вкладок со стильной анимацией вращения, а также горячие клавиши `Ctrl+R` и `F5`. При перезагрузке обновляются результаты поиска для текущей вкладки.
- **Контекстное меню (правый клик по вкладке):**
  * ↻ Перезагрузить вкладку
  * 📋 Дублировать вкладку (создание точной копии)
  * ➕ Новая вкладка
  * ❌ Закрыть вкладку
  * 🚫 Закрыть другие вкладки
- **Быстрое переключение:** комбинация `Ctrl+Tab` и `Ctrl+Shift+Tab`.

### 3. 🖤 Ультра-лаконичный черный стиль (OLED Black) по умолчанию
- Основной интерфейс переведён на глубокий истинный чёрный цвет (`#000000`).
- Идеален для OLED-дисплеев, бережёт зрение при ночной работе и создаёт бескомпромиссный минималистичный внешний вид.

### 4. 🎨 Коллекция стилей оформления приложения
В разделе **«Настройки» → «Оформление»** (а также в выпадающем меню профиля) доступна интерактивная галерея тем:
1. 🖤 **OLED Black (По умолчанию)** — глубокий истинный чёрный стиль.
2. ⚪ **Классический Искатель (Старый стиль)** — оригинальная светлая градиентная тема, которую можно включить в один клик.
3. 🌌 **Midnight Navy** — глубокий космический полуночно-синий стиль.
4. ⚡ **Киберпанк** — высокотехнологичный тёмный стиль с неоновым цианом и маджентой.
5. 🪨 **Графит** — строгий матовый тёмно-серый монохром.
6. 🌲 **Изумрудная ночь** — благородный хвойно-зелёный глубокий тёмный стиль.
7. ❄️ **Скандинавский** — чистый снежно-белый светлый минимализм.

## 🌟 Возможности Proton

- **👤 Вход через Google (Gmail) и профили:** привязка почты Gmail в один клик, локальное безопасное хранилище с криптографическим SHA-256 хешированием паролей.
- **⭐ Персональные закладки:** возможность сохранять сайты в избранное звёздочкой ☆ прямо из результатов поиска.
- **🔍 Минималистичный Omnibox:** поле ввода без лишних кнопок со встроенной кнопкой перехода `→` и мгновенным поиском по `Enter`.
- **🛡️ Конфиденциальность:** никаких скрытых трекеров, телеметрии и передачи данных рекламным сетям.

## 🪟 Инструкция по запуску на Windows

### Вариант 1 (Рекомендуется): Портативная версия (Без прав администратора)
- Скачайте [`iskatel-win64-portable.exe`](https://github.com/UsmanMusav/Iskatel/releases/download/v2.7.0/iskatel-win64-portable.exe).
- Приложение **не требует установки и прав администратора** — запускается сразу двойным кликом.

### Вариант 2: Если Windows SmartScreen блокирует запуск
1. В синем окне «Система Windows защитила ваш компьютер» нажмите ссылку **«Подробнее»** (*More info*).
2. Нажмите появившуюся кнопку **«Выполнить в любом случае»** (*Run anyway*).

---

## 🍏 Инструкция по установке на macOS

1. Скачайте `.dmg` файл под вашу архитектуру (Apple Silicon для M1/M2/M3/M4 или Intel).
2. Перетащите «Proton» в системную папку **«Программы»** (Applications).
3. При первом открытии: правый клик → **«Открыть»** → подтвердить.
4. *(Если Gatekeeper блокирует запуск)* выполните команду в Терминале:
   ```bash
   xattr -cr "/Applications/Proton.app"
   ```
