# «Искатель» 2.6 — Минималистичный браузер и десктопный поисковик

«Искатель» — быстрое, ультра-минималистичное и легкое настольное приложение на Electron для приватного поиска в интернете без рекламы, слежки, трекеров и визуального шума. Приложение объединяет результаты нескольких независимых поисковых систем (DuckDuckGo и Bing), умеет показывать карточки Русской Википедии, мгновенные ответы, поддерживает аккаунты Google (Gmail) и персональные закладки.

---

## 🚀 Что нового в версии 2.6: Минимализм и чистый интерфейс

### 1. 🧹 Полная очистка от лишних кнопок (True Minimalism)
- **Удалены лишние кнопки главной страницы:** убран архаичный блок кнопок «Мне повезёт» и «Найти» под поисковой строкой.
- **Удалена загромождающая лента чипсов:** убран блок «Популярное» с кучей случайных кнопок-подсказок. Главный экран теперь чистый, просторный и сфокусированный.
- **Удалена плавающая кнопка в углу экрана:** убран висящий виджет версии из правого нижнего угла, перекрывавший контент.
- **Удалена кнопка «Наверх» из подвала:** лаконичный, ненавязчивый подвал приложения в одну строку.

### 2. 🔍 Новая минималистичная поисковая строка (Omnibox)
- Поисковая строка объединяет поиск и ввод веб-адресов.
- Аккуратная встроенная круглая кнопка перехода `→` прямо внутри поля ввода.
- Мгновенный поиск по нажатию клавиши `Enter`.
- Удобная кнопка быстрой очистки `✕`, появляющаяся только при наборе текста.

### 3. 🎯 Лаконичная верхняя панель (Header)
- Дублирующие кнопки удалены:
  - При авторизации в системе в шапке отображается только стильный аватар профиля.
  - Кнопка смены темы и кнопка настроек аккуратно перенесены в выпадающее меню профиля:
    * 🌓 Быстрое переключение темы (Светлая / Тёмная)
    * ⭐ Персональные закладки
    * ⚙️ Настройки и кастомизация
    * 🚪 Выход из аккаунта
  - Для неавторизованных пользователей остаются только кнопка «Войти» и одна компактная шестерёнка настроек.

- **🛡️ Конфиденциальность:** полное отсутствие телеметрии, слежки, рекламных трекеров и передачи личной информации третьим лицам.

## 🪟 Инструкция по запуску на Windows

### Вариант 1 (Рекомендуется): Портативная версия (Без прав администратора)
- Скачайте [`iskatel-win64-portable.exe`](https://github.com/UsmanMusav/Iskatel/releases/download/v2.6.0/iskatel-win64-portable.exe).
- Приложение **не требует установки и прав администратора** — запускается сразу двойным кликом.

### Вариант 2: Если Windows SmartScreen блокирует запуск
1. В синем окне «Система Windows защитила ваш компьютер» нажмите ссылку **«Подробнее»** (*More info*).
2. Нажмите появившуюся кнопку **«Выполнить в любом случае»** (*Run anyway*).

### Вариант 3: Запуск от имени администратора (для Setup)
1. Нажмите правой кнопкой мыши по файлу `iskatel-win64-setup.exe`.
2. Выберите **«Запуск от имени администратора»** (*Run as administrator*).
3. В окне UAC подтвердите запуск кнопкой «Да».

## 🍏 Инструкция по установке на macOS

1. Скачайте `.dmg` файл под вашу архитектуру (Apple Silicon для процессоров M1/M2/M3/M4 или Intel).
2. Перетащите «Искатель» в системную папку **«Программы»** (Applications).
3. При первом открытии: правый клик → **«Открыть»** → подтвердить.
4. *(Если Gatekeeper блокирует запуск)* выполните команду в Терминале:
   ```bash
   xattr -cr "/Applications/Искатель.app"
   ```

## 💻 Локальный запуск и сборка

```bash
git clone https://github.com/UsmanMusav/Iskatel.git
cd Iskatel
npm install
npm start
```

Сборка дистрибутивов:
- `npm run dist:win` — Windows 64-bit установщик и portable-версия
- `npm run dist:linux` — пакет Debian/Ubuntu (.deb)
- `npm run dist:mac` — образы macOS (.dmg)
